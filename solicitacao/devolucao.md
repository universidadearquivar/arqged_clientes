# 🟩 Devolução

Depois de receber e concluir a consulta aos documentos físicos, caixas e ou subcaixas, o cliente deverá devolvê-los para a guarda, sendo a guarda realizada na unidade Arquivar ou no CEDOC do cliente, o processo no sistema precisa ser realizado para registro da movimentação.

Para realizar a devolução, o cliente (solicitante) precisa abrir uma solicitação no menu Solicitação > Devolução.

<figure><img src="../.gitbook/assets/image (209).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

**Empresa:** Exibe o nome do cliente. Quando o cliente tiver tanto o serviço de Guarda Terceirizada quanto de Guarda Interna (CEDOC), neste momento ele deverá selecionar a guarda correspondente a sua devolução.

<figure><img src="../.gitbook/assets/image (210).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

**Documento / Caixa ou subcaixa:** Botão utilizado para identificar o volume que será devolvido. Selecione conforme acervo disponível para devolução.

**Quando selecionado > Documento:**

<figure><img src="../.gitbook/assets/image (211).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

**Quando selecionado > Caixa ou Subcaixa:**

<figure><img src="../.gitbook/assets/image (212).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

Selecionado o volume, informe no espaço indicado o (s) código (s) correspondente (s) e clique em validar.

<figure><img src="../.gitbook/assets/image (213).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

O ArqGED realiza a validação tanto do código de consulta quanto dos códigos de caixa e subcaixa na base do cliente. Caso identificado algum problema, será apresentada uma mensagem na tela e não é possível seguir com o atendimento.

<figure><img src="../.gitbook/assets/image (214).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

{% hint style="danger" %}
<mark style="color:red;">Quando a devolução for de documento, o código solicitado é o mesmo utilizado no atendimento da consulta, ou seja, o código gerado de forma automática pelo sistema e anotado no verso do documento, e não o código do registro no ArqGED.</mark>
{% endhint %}

Caso neste momento outro usuário esteja tentando devolver o mesmo documento, o sistema deverá apresentar a mensagem “Em processo de devolução”.

Quando o código é validado, é apresentado o botão “Avançar”.

<figure><img src="../.gitbook/assets/image (215).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

Selecione se haverá coleta e o endereço quando aplicar, depois clique “Avançar”.

<figure><img src="../.gitbook/assets/image (216).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

Consolidados os dados da devolução, clique “Enviar”.

A devolução é concluída e enviada para a Unidade ou para o CEDOC.

Neste momento o sistema gera de forma automática o Protocolo de Devolução (Documento ou Caixa e/ou Subcaixa).

<figure><img src="../.gitbook/assets/image (217).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

O protocolo de devolução deve ser validado e assinado pelo responsável CEDOC no momento da coleta ou do recebimento do acervo.

<figure><img src="../.gitbook/assets/image (218).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

{% hint style="info" %}
<mark style="color:blue;">O usuário poderá acessar o Painel de Atendimento para acompanhar o atendimento, porém, ele não poderá realizar nenhuma outra interação no pedido.</mark>
{% endhint %}
